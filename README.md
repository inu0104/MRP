# Label-wise Monotone Reliability Projection (MRP)

Code and paper artifacts for:

> **Post-Calibration Reliability Reranking of Relevance Decisions via Label-wise Monotone Projection**
> Inwoo Tae and Yongjae Lee. CIKM '26.
> Preprint: https://arxiv.org/abs/2608.10406
> DOI: `10.1145/3799682.3840940` (resolves after publication)

![Overview of MRP. Each row is a fixed query-candidate relevance prediction. Post-hoc calibration updates the confidence of the predicted label; MRP then maps that calibrated confidence to label-wise correctness reliability and reranks the same predictions by estimated risk. Reranking by calibrated confidence and by MRP reliability can differ.](paper/figure/mrp_method_overview.png)

Post-hoc calibration aligns confidence with *average* correctness, but predictions that share the same calibrated confidence can still differ in correctness risk depending on which relevance label was predicted. MRP addresses this residual structure: it keeps the calibrated class probabilities and the predicted label fixed, and learns a label-wise monotone map from calibrated confidence to correctness reliability. The resulting score is used only to rerank fixed predictions for fallback, review, or selective use, so full-coverage accuracy and ECE are unchanged by construction.

## Repository Structure

- `calibration/` — post-hoc calibrators and the name registry.
- `configs/calibration/` — default calibrator hyperparameters.
- `experiments/text/` — dataset preparation scripts that train the base predictor and write saved logits.
- `experiments/table/` — evaluation scripts that fit MRP and regenerate the paper tables and figures.
- `experiments/figures/` — standalone diagram scripts.
- `paper/table/`, `paper/figure/` — the tables and figures used in the paper.

Raw datasets, caches, saved logits, checkpoints, run directories, and intermediate CSVs are not tracked. They live under `.local/`, `data/`, `cache/`, `runs/`, or `results/`, all git-ignored.

## Datasets

Six relevance-prediction datasets spanning product search, web search, QA retrieval, e-commerce reranking, and scientific document retrieval:

| Dataset | Setting |
| --- | --- |
| Amazon ESCI | product search, graded |
| WANDS | product search, graded |
| MSLR-WEB10K | web relevance, graded |
| Alloprof-Rerank | retrieval reranking |
| SciDocs | scientific retrieval reranking |
| ESCI-Rerank-US | e-commerce reranking, binary |

For SciDocs, Alloprof-Rerank, and ESCI-Rerank-US the train/validation/test split is **query-disjoint** (`split_query_ids()` in the corresponding preparation script). Amazon ESCI, WANDS, and MSLR-WEB10K use the splits provided with the dataset.

## Base Predictor

The base predictor is deliberately lightweight. The point is to fix one prediction source that calibrators and MRP can be compared on, not to build a strong ranker.

For text query–candidate datasets it is a linear classifier over the concatenated query and candidate text:

- `TfidfVectorizer(lowercase=True, ngram_range=(1, 2), min_df=3, max_features=80000, sublinear_tf=True)`
- `SGDClassifier(loss="log_loss", alpha=1e-5, max_iter=14, tol=1e-4, class_weight="balanced")`

For MSLR-WEB10K the provided learning-to-rank features are used directly. `experiments/text/mslr_web10k_lightgbm_logit_prep.py` trains a stronger, better-calibrated LightGBM base and writes logits in the same format. The paper uses it as a robustness check.

## Preparing Saved Logits

Each preparation script reads the configured public dataset, trains the base predictor, and writes a run directory under `.local/runs/relevance_projection/` containing `metadata.json` and `logits_and_labels.npz` (validation/test logits and labels). The table pipeline reads only these files, so raw datasets are never committed.

```sh
python3 experiments/text/amazon_esci_logit_prep.py
python3 experiments/text/wands_logit_prep.py
python3 experiments/text/mslr_web10k_logit_prep.py
python3 experiments/text/mteb_qrels_logit_prep.py        # Alloprof-Rerank
python3 experiments/text/mteb_reranking_logit_prep.py    # SciDocs
python3 experiments/text/esci_rerank_us_logit_prep.py
```

## Reproducing the Paper

After preparing saved logits:

```sh
CUDA_VISIBLE_DEVICES=0 PYTHONHASHSEED=2026 sh experiments/table/run_fixed_decision_mrp_main.sh
```

This writes intermediate CSVs under `results/` and regenerates the artifacts under `paper/`:

| Paper artifact | Generated by |
| --- | --- |
| `paper/table/main_mrp_table.tex` | `make_mrp_main_table.py` |
| `paper/table/budgeted_fallback.tex` | `make_budgeted_fallback_table.py` |
| `paper/table/label_conditional_residual.tex` | `analyze_mrp_structure.py` |
| `paper/table/mrp_ablation_results.tex` | `make_mrp_ablation_table.py` |
| `paper/table/simplex_projection.tex` | `make_mrp_space_artifacts.py` |
| `paper/figure/mrp_labelwise_curves.pdf` | `analyze_mrp_structure.py` |
| `paper/figure/mrc_simplex_schematic.pdf` | `make_mrc_schematic.py` |

`paper/table/datasets.tex` and `paper/figure/mrp_method_overview.pdf` are hand-authored. `mrp_method_overview.png` is a PNG copy of that figure for display in this README.

To read the numbers without LaTeX, see **[`paper/`](paper/)**. Its README is generated from the same `.tex` files, so the two stay in sync:

```sh
python3 experiments/table/export_markdown_tables.py           # regenerate
python3 experiments/table/export_markdown_tables.py --check   # fail if stale
```

The protocol is fixed across datasets: base predictor from model seed 0, calibrator and MRP refit under protocol seeds 1–3, projection-fit and projection-selection capped at 8000 samples each. MRP uses `J = 8` confidence knots, second-difference coefficient `1e-4`, Adam with learning rate 0.03, and at most 400 epochs. Runs used PyTorch 2.1.0 with CUDA 12.1 on a single NVIDIA RTX A5000.

## Changing Calibrators

The main script evaluates:

```sh
COMMON_BASES="raw ts diag spline hcal smart"
```

Edit this list in `experiments/table/run_fixed_decision_mrp_main.sh`, or pass `--methods` to the underlying scripts. Registered names are `raw`, `ts`, `diag`, `spline`, `hcal`, `smart`, `iso`/`isotonic`, and `dir`/`dirichlet` (`calibration/registry.py`). The paper reports the first six. `isotonic` and `dirichlet` are implemented but not used in it.

## Applying MRP to a New Dataset

Produce saved logits in the same format as the preparation scripts, add a dataset key and local glob pattern to `dataset_config()` in `experiments/table/mrp_final_utils.py`, then pass that key via `--datasets`. Your dataset and model code only has to write the logits; the shared table scripts handle calibration and MRP evaluation.

## Scope

This repository holds the source code, configuration, and the tables and figures used in the paper. Datasets, checkpoints, caches, and build products are left out, as are exploratory scripts that none of the reported results depend on.
